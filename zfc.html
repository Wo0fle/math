background

so what's wrong with the sets we had before?

the main issue is that we could make sets of literally anything.
  • the empty set? sure.
  • the set of all natural numbers? sounds good to me!
  • the set of all sets which do not contain themselves? i guess bro
  • the set of... wait

the set of all sets which do not contain themselves... is that actually allowed?

in our old system, there's nothing stopping us from creating it:
  • a set is a collection of objects
  • sets which do not contain themselves are objects
  • collect all of those
  • you're left with a set (which contains all sets which do not contain themselves)

this by itself doesn't violate any of the laws of logic we agreed on originally, but consider this proposition: $$\text{The set of all sets that do not contain themselves contains itself.}$$ is this true? according to the law of excluded middle, it has to be either true or false, so let's try to find out which one it is. $$ \text{Let }A=\{x:x\notin x\}\\\\ \text{If }A\in A\text{, then }A\text{ must satisfy the membership statement, so }A\notin A\\ A\in A\rightarrow A\notin A\text{... contradiction}\\\\ \text{If }A\notin A\text{, then }A\text{ satisfies the membership statement, so }A\in A\\ A\notin A\rightarrow A\in A\text{... contradiction} $$ hold up, wait a minute... somethin' ain't right.

"Gottem."
- Bertrand Russell, 1901

what we've stumbled upon here is called Russell's paradox, and it shows that set theories with unrestricted comprehension (AKA "any collection of things is a set") lead to contradictions.

this is what mathematicians call "really freaking bad," since it means that the logical system that was being used has "holes" in it, so to speak. so how was this addressed?

well, mathematicians back in the day had to sit down and answer these questions:
  • what are the basic concepts that form the basis of all of mathematics? i.e. what are the "fundamental particles" of math?
  • what rules must these concepts follow? i.e. what are the "laws of physics" (axioms) of math?

answering these questions properly would mean the birth of a system of mathematics which would be "perfect."

so, some really smart people did some really smart things, and today, we have ZFC set theory.

ZFC is the name given to Zermelo-Fraenkel set theory with the Axiom of Choice, the contributors being the namesakes Ernst Zermelo and Abraham Fraenkel, as well as other guys who helped out but apparently don't get to put their name on the system for some reason, such as Thoralf Skolem and John von Neumann.

so great! we found the perfect mathematical system now, right?

"Nah."
- Kurt Gödel, 1931

wellllllllll, Gödel actually showed that it is impossible to create a perfect mathematical system: every axiomatic system of math will have some inconsistencies or some unprovable statements.

however, there is no need to fret! instead of trying to create a perfect mathematical system, we can just pick one that works really well for the types of questions we want to answer, and ZFC happens to be that! this does mean, though, that there are "alternate mathematical universes" based on different axioms... which is awesome!

but enough about the math multiverse... let's get into ZFC!

axioms

the language of ZFC is based on these fundamental building blocks:
  • logical connectives: \(\wedge\), \(\vee\), \(\neg\), etc.
  • variables
  • quantifiers: \(\forall\), \(\exists\)

this means that the laws of logic/proof techniques that we learned about before still work; we are just formalizing sets.

additionally, on top of the philosophical laws of logic from before, we will add our own rules, called axioms, regarding mathematical objects within ZFC.

let's go through them!
  1. Axiom of Existence: there exists a set. $$\exists x,x=x$$ congratulations! this is the very first building block of our mathematical universe: the set.

    ZFC's basic concept is the set, and everything else that you will later recognize (numbers, functions, etc.) will be made of sets.

    all this axiom says is that there is a set; we don't know what it is yet, but it's there!

    actually, we haven't said what a set is yet either. for that, we will need...

  2. Axiom of Extensionality: sets are defined by their elements. $$\forall x \forall y, ((\forall z, z\in x\leftrightarrow z\in y)\leftrightarrow x=y)$$ this axiom says if two sets have the same elements, then they are the same set.

    so great, we now know that sets have stuff in them, and that the stuff that is in them is what defines them.

    notice that this axiom says nothing about the order of elements; it just says if each element in one set is in the other (and this is true both ways), then the sets are the same.

    we have now recovered the notion of a set being an "unordered collection of distinct objects," but we need to define some more rules to help create more sets!

  3. Axiom of Pairing: for any two sets, there is a set containing those two. $$\forall x \forall y \exists z \forall u, (u\in z\leftrightarrow (u=x\vee u=y))$$ this axioms says that for any two sets \(x,y\), there exists a set \(\{x,y\}\).

  4. Axiom of Union: the union of any set of sets exists. $$\forall x \exists y \forall z, (z\in y\leftrightarrow \exists u\in x, z\in u)$$ this is NOT the normal union operation \(\cup\) between two sets; this axiom defines the big union operation \(\bigcup\) which combines all the elements of the elements of a set into its own set.

    that was kind of a mouthful, so it might be more insightful to see an example of how the Pairing and Union axioms work together to form the normal \(\cup\) operation between two sets: $$ a=\{p,q,f\}, b=\{n,m,g\} \\ X=\{a,b\}\text{ by Pairing axiom} \\ \bigcup X=\{p,q,f,n,m,g\}\text{ by Union axiom} \\ a\cup b=\bigcup X $$
